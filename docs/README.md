## Как читать статусы

- **Реализовано в прототипе** — соответствующий код или сцена есть в репозитории. Это не гарантия законченного или отбалансированного поведения.
- **Концепция** — правило или элемент присутствует в дизайн-заметках, но полноценная реализация в проекте не подтверждена.
- **Идея / не решено** — предложение или вопрос без принятого решения.
- **Частично** — есть заготовка или отдельная часть поведения, но до описанного игрового результата еще нужно дойти.

В инспекторе Unity значения могут переопределяться сериализованными настройками объектов сцены и префабов. Значения из полей скриптов в техническом обзоре — исходные значения по умолчанию, а не гарантированные значения игрового экземпляра.

## Источник истины

Для текущего поведения источником истины является сцена и код в `Assets/`. Для планируемого дизайна — этот раздел документации и исходные дизайн-заметки. При расхождении нужно обновить документацию или явно пометить идею как устаревшую; не следует выдавать концепт за готовую механику.
