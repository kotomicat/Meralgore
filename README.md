# METALGORE

METALGORE — шутер-рогалик с быстрым боем, накапливающимися билдами и эстетикой низкополигональных игр эпохи PlayStation 2. Игрок поднимается по этажам движущейся мегаструктуры, сражается, исследует комнаты и собирает сочетания оружия и модификаторов.

> **Статус:** ранний Unity-прототип. В проекте уже есть тестовая сцена, базовое передвижение, несколько скриптов оружия и отладочный интерфейс. Генерация этажей, полноценный цикл забега, большинство предметов и аффиксов, враги и боссы пока описаны как дизайн, а не реализованы как законченные системы.

## Быстрый старт

1. Установите Unity Editor **6000.5.6f1** (актуальная версия проекта указана в `ProjectSettings/ProjectVersion.txt`).
2. Откройте папку репозитория через Unity Hub.
3. В Unity откройте `Assets/Scenes/test.unity`.
4. Нажмите **Play**.

## Управление в прототипе

| Действие | Клавиша / кнопка |
|---|---|
| Движение | `W`, `A`, `S`, `D` |
| Перейти в режим ходьбы | удерживать `Shift` |
| Прыжок | `Space` |
| Присесть или скользить | удерживать `Ctrl` |
| Основная атака | левая кнопка мыши |
| Альтернативная атака | правая кнопка мыши |
| Перезарядка | `R` |
| Слоты оружия | `1`–`4` |

Поведение отдельных действий зависит от выбранного оружия и настроек компонентов сцены. Подробности и различия между планом и текущим прототипом приведены в [документации по игровым системам](docs/gameplay.md).

## Структура проекта

- `Assets/Characters/Player/` — управление игроком, камера и переключение оружия.
- `Assets/Characters/Enemies/` — заготовки врагов и компонент здоровья.
- `Assets/Weapon/` — базовый класс оружия и прототипы оружия.
- `Assets/Scenes/` — Unity-сцены; текущая тестовая сцена — `test.unity`.
- `Assets/UI/` — прототип отладочного интерфейса.
- `Assets/Resourses/` — материалы, спрайты и ресурсы окружения (историческое написание папки сохранено).
- `Packages/manifest.json` — зависимости Unity Package Manager.
- `ProjectSettings/` — настройки проекта Unity.

## Статус документации

Документация отражает идеи из дизайн-заметок и наблюдаемое состояние репозитория. Она не подразумевает, что все описанные механики уже реализованы. В спорных местах отдельно обозначено, что является текущей реализацией, концепцией или открытым вопросом.
